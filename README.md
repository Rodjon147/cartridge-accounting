# Наименование проекта

Система учёта картриджей и принтеров для IT-отдела компании.

Выполнил Шипко Р.А.
Группа АСУбз-25-1

---

# Цель проекта

Создание информационной системы для учета картриджей, обеспечивающей централизованное хранение данных о складских запасах, контроль поступления и выдачи картриджей, мониторинг остатков и формирование истории операций.

---

# Краткое описание проекта

Проект представляет собой web-приложение для управления складом картриджей, контроля остатков, отслеживания движения и истории операций.
